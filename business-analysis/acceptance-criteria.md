# Acceptance Criteria

## US-001
Given an API has a configured SLA,
when performance data is loaded,
then availability, response time and error rate shall be compared with the configured thresholds.

## US-002
Given an API has breached its SLA,
when the API exists in the business mapping,
then the affected business process and criticality shall be displayed.

## US-003
Given a breach is detected,
when an AI summary is requested,
then the output shall identify observations and investigation areas without inventing unsupported root causes.

## US-004
Given multiple API records exist,
when the dashboard is opened,
then SLA compliance, breach count and critical breach count shall be displayed.
