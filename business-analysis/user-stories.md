# User Stories

## US-001 — SLA Monitoring
As a Business Analyst, I want API metrics compared with SLA thresholds so that breaches are identified automatically.

## US-002 — Business Impact
As a Product Owner, I want an API breach mapped to its business process so that I can understand potential business impact.

## US-003 — Incident Summary
As an Operations Manager, I want a concise incident summary so that I can quickly understand the issue and follow-up required.

## US-004 — Management Reporting
As a Business Manager, I want SLA compliance KPIs so that recurring service issues can be reviewed.
