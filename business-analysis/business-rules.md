# Business Rules

BR-01: Availability below the configured SLA is a breach.

BR-02: Response time above the configured SLA is a breach.

BR-03: Error rate above the configured SLA is a breach.

BR-04: A Critical API with two or more simultaneous SLA dimensions breached is classified as Critical.

BR-05: A Critical or High API with a breach is classified as High unless BR-04 applies.

BR-06: Other SLA breaches are classified as Medium.

BR-07: AI output is advisory and requires BA/business review before external communication.
